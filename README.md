# 💾 نسخ التعريفات — Windows Driver Toolbox

برنامج ويندوز بواجهة عربية لأخذ نسخة احتياطية من تعريفات الجهاز (كرت الشاشة، الصوت، الشبكة، اللوحة الأم…) واستعادتها بعد تهيئة الويندوز أو عند حدوث مشكلة.

## ⬇️ التنزيل

### [تنزيل أحدث إصدار DriverToolbox.exe](https://github.com/adelss12/DriverBackup/releases/latest)

ملف واحد يعمل مباشرة، ويطلب صلاحيات المسؤول عند فتحه (ضرورية لتصدير التعريفات وتثبيتها).

> قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً. اضغط **More info** ثم **Run anyway**.

## 🌟 المميزات

- **اختيار ما تنسخه:** تضع علامة ✓ على الفئات (كرت الشاشة، اللوحة الأم، الشبكة، الصوت، البلوتوث، الطابعات، الكاميرا، الفأرة ولوحة المفاتيح)، ويظهر بجانب كل فئة عدد تعريفاتها وحجمها وأسماء القطع.
- **«المستخدمة حاليًا فقط»:** يتجاهل الإصدارات القديمة المتراكمة من التعريفات، فيصغر حجم النسخة كثيرًا.
- **نسخة كاملة عند الحاجة:** يستخدم أدوات ويندوز الرسمية، ويجرّب تلقائياً DISM ثم PowerShell ثم PnPUtil إذا فشلت الأداة الأولى.
- **كل نسخة في مجلد مستقل** باسم الجهاز والتاريخ داخل `BackupDriver` بجانب البرنامج، فلا تختلط النسخ ببعضها.
- **مواصفات الجهاز** محفوظة مع كل نسخة (الشركة، الموديل، ويندوز، الرقم التسلسلي).
- **استعادة آمنة:**
  - تختار النسخة من قائمة، ويطلب البرنامج تأكيداً قبل البدء.
  - **ينبّهك إذا كانت النسخة من جهاز بموديل مختلف** عن جهازك الحالي.
  - نتيجة دقيقة لكل تعريف: نجح، أو يحتاج إعادة تشغيل، أو أُضيف للنظام دون جهاز يحتاجه الآن (وهذا طبيعي)، أو فشل.
  - تقرير استعادة يُحفظ داخل مجلد النسخة.
- **تصدير ZIP** لأي نسخة إلى قرص خارجي، مع ملف بصمة تحقق SHA-256.
- **يتعرف على النسخ القديمة** المحفوظة في `BackupDriver` أو `DriversBackup` من الإصدارات السابقة.

## 📋 طريقة الاستخدام

1. **قبل تهيئة الويندوز:** شغّل البرنامج واضغط **«نسخة احتياطية جديدة»**، ثم **«تصدير ZIP»** إلى فلاش أو قرص خارجي.
2. **بعد التهيئة:** انسخ البرنامج ومجلد `BackupDriver` (أو فك ملف ZIP بجانبه)، ثم اختر النسخة واضغط **«استعادة النسخة المحددة»**.
3. أعد تشغيل الجهاز إذا طلب البرنامج ذلك.

## 🛠️ للمطور

التشغيل من الكود (يحتاج Python 3 على ويندوز، كمسؤول):

```bash
python driver_toolbox.py
```

يُبنى ملف EXE تلقائياً على خوادم GitHub كلما تغيّر الكود، باسم رقم الإصدار المكتوب في `APP_VERSION` (ملف `.github/workflows/build-exe.yml`). للبناء يدوياً:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --uac-admin --name DriverToolbox driver_toolbox.py
```

> الإصدار 3.0 يجمع في برنامج واحد ما كان موزعاً على القائمة الإنجليزية والأداتين المستقلتين وواجهة HTA. الملفات القديمة محفوظة في سجل Git.
